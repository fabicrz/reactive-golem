# Reactive Golem — Interactive Character
Um projeto web interativo que apresenta um golem inspirado no estilo LEGO em um cenário ilustrado de floresta. O personagem possui interações simples, como tremores acionados por clique, piscadas automáticas e movimentação por arrastar e soltar.

## Funcionalidades

- **Personagem interativo:** um golem no estilo LEGO em um ambiente inspirado em florestas.
- **Piscadas automáticas:** o personagem pisca periodicamente para dar vida à animação.
- **Efeito de tremor:** clique no personagem para acionar uma animação de tremor.
- **Arrastar e soltar:** clique e arraste o personagem para movê-lo pela tela.
- **Folhas cadentes:** folhas animadas complementam a atmosfera da floresta.
- **Cenário ilustrado:** um ambiente visual inspirado na natureza.
- **Instruções interativas:** a interface apresenta orientações sobre como interagir com o personagem.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- SVG

## Objetivo

Explorar interações com personagens, animações leves e narrativa visual por meio de uma experiência web.
